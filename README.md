# lock_pc

Скрипт следит за веб-камерой и блокирует экран, если за компьютером никого нет.
Работает на **Linux** и **Windows**.

## Что делает

Раз в несколько секунд скрипт снимает кадр с камеры и проверяет четырьмя способами,
есть ли человек за компом:

1. **YuNet** — детектор лиц (OpenCV DNN). Ловит лицо анфас и в профиль до ~60–70°.
2. **Upper body** — каскад Хаара «голова + плечи + грудь». Срабатывает, когда
   лицо наклонено вниз (смотришь на клавиатуру/телефон) и YuNet промахивается.

Кадры никуда не сохраняются и не передаются. Анализ идёт в памяти.

## Требования

- Python 3.8+
- OpenCV 4.5.4+ (нужен `cv2.FaceDetectorYN`)
- Веб-камера
